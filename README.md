# fNIRS-mat-to-nirs
Convert the fNIRS raw data from time series data to nirs format file

You can read and use the code to convert the fNIRS raw data from a mat file or Excel in time series data to nirs format file.
Here are two website can help you understand
https://www.nitrc.org/plugins/mwiki/index.php/homer2:Homer_Input_Files#NIRS_data_file_format
https://github.com/BUNPC/Homer3/wiki
